# student-course-registration
Tkinter + MySQL student course registration system
Project: Student Course Registration System

Description:
This is a Python Tkinter application connected to a MySQL database.
It allows users to:

* Add students
* Add courses
* Register students to courses
* View and delete registrations

How to run:

1. Install MySQL and Python
2. Install mysql connector:
   pip install mysql-connector-python
3. Run setup_database.py first
4. Then run student_course_registration.py

Database:
MySQL (student_course_db)
